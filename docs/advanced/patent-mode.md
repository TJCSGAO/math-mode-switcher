# 专利 / 论文增强说明

这个文档面向对公式规范性要求更高的场景，例如专利交底书、专利正文、论文初稿、技术报告和审校流程。

## 推荐增强规则

- 默认优先 `双模式`，先审视觉效果，再取源码落稿
- 对关键变量采用更清晰的命名，如 `\tau_{\mathrm{opt}}`、`\mathbf{x}_{\mathrm{opt}}`
- 少用容易模糊的星号最优符号，如 `\tau^*`
- 多行公式优先使用 `aligned`
- 需要复制进正式稿件时，优先要求 `源码模式（latex）`

## 推荐口令

- `模式：双模式。按专利/论文风格输出，变量命名要清晰，避免含糊符号。`
- `模式：源码（latex）。请给我适合正式稿件的公式代码，命名尽量审查友好。`
- `模式：渲染。先让我检查大公式排版是否清楚。`

## 典型收益

- 降低公式符号歧义
- 减少后续人工改写量
- 让“看效果”和“拿源码”两个动作连续完成
- 提高跨轮对话中的格式稳定性
