# 公式显示模式切换（math-mode-switcher）

本 Skill 用于**在同一次对话中稳定、可控地切换数学公式的呈现方式**，解决以下常见问题：
- 想看别人给的 LaTeX 公式“最终渲染长什么样”
- 想把公式复制到 PDF/Word/专利文档里，因此需要“源码”
- 既要看效果又要拿走可复制源码
- 避免把公式放进代码块导致“不渲染”

## 触发场景（何时调用）

满足任一条件就应调用本 Skill：
- 用户明确说：`渲染模式` / `源码模式` / `双模式`
- 用户说：想“看看渲染出来啥样”、想“可复制源码”、想“切换显示模式”
- 用户提供了一段 LaTeX 并希望看到排版效果
- 用户要把公式用于 `pdf` / `LaTeX` / `Word` / 专利文档生成（通常需要源码）

## 总体约定

- **渲染模式**：输出中公式必须直接渲染显示，行内用 `$...$`，块级用 `$$...$$`，并**禁止**把公式放在 ```latex``` 代码块里。
- **源码模式**：只输出可复制的公式代码（Markdown 或 LaTeX），**不追求渲染展示**；如需代码块，统一用普通 ```text```（避免被系统当作“需要渲染的 LaTeX”而产生不一致行为）。
- **双模式**：先给渲染效果，再给对应源码（明确标注是 `Markdown` 还是 `LaTeX`）。

## 模式识别规则（优先级）

按以下优先级决定输出模式：
1. 用户消息首行命中 `模式：渲染/源码/双模式`
2. 用户消息中包含明确关键词：`渲染模式`、`源码模式`、`双模式`
3. 若用户未指定模式：
   - 用户要“看看渲染效果/排版” → 默认 `渲染模式`
   - 用户要“复制/用于 PDF/用于 Word/用于 LaTeX/生成 pdf” → 默认 `源码模式（LaTeX）`
   - 其余情况 → 默认 `双模式`

## 输出规范

### 渲染模式输出规范

- 行内公式：`$...$`
- 块级公式：`$$...$$`
- 多行推导：`aligned` 环境放入 `$$...$$`
- 绝不使用 ```latex``` 代码块包裹需要渲染的公式
- 变量命名清晰、审查友好：优先 `\\tau_{\\mathrm{opt}}`，避免 `\\tau^*` 等易糊/易歧义写法

渲染模式示例（应该直接显示为渲染后的公式）：

行内：$E=mc^2$

块级：
$$
\\tau_{\\mathrm{opt}} = \\arg\\min_{\\tau\\in\\Omega} \\mathcal{L}(\\tau)
$$

多行：
$$
\\begin{aligned}
J(\\mathbf{x}) &= \\sum_{i=1}^{n} w_i \\,\\phi_i(\\mathbf{x}) \\\\
\\mathbf{x}_{\\mathrm{opt}} &= \\arg\\min_{\\mathbf{x}\\in\\mathcal{X}} J(\\mathbf{x})
\\end{aligned}
$$

### 源码模式输出规范

源码模式要先问清楚（或根据上下文判断）输出格式：
- `源码模式（Markdown）`：输出 `$...$` / `$$...$$` 风格，便于粘贴到 Markdown/部分编辑器
- `源码模式（LaTeX）`：输出 `\\(...\\)` / `\\[...\\]` 或 `equation/aligned` 等纯 LaTeX 数学环境，便于放进论文/专利 LaTeX 工程

源码输出要求：
- 只给代码，不混入渲染展示型文字
- 必要时用普通代码块：```text ... ```
- 如用户要求“可直接用在 PDF”，优先给 `LaTeX` 版本

源码模式（LaTeX）示例（只输出代码，便于复制）：

```text
\\begin{equation}
\\tau_{\\mathrm{opt}} = \\arg\\min_{\\tau\\in\\Omega} \\mathcal{L}(\\tau)
\\end{equation}
```

### 双模式输出规范

输出结构固定为两段：
- `渲染：`（直接展示渲染效果）
- `源码（Markdown）` 或 `源码（LaTeX）`（可复制代码，放入 ```text``` 代码块）

## 交互提示（只在必要时问）

仅当用户说“源码模式”但未指定 `md` 或 `latex`，且上下文无法推断时，才问一句：
- “你要 `Markdown` 公式源码还是 `LaTeX` 工程可用源码？”

## 常见坑位与纠正策略

- 若用户抱怨“独立公式没渲染”：优先改为 `$$...$$` 且移除 ```latex``` 代码块
- 若用户说“我要源码但你给我渲染了”：立即切到源码模式，用 ```text``` 输出可复制代码
- 若用户给了复杂环境（如 `cases/matrix`）且渲染失败：先给源码模式（LaTeX），再给一个尽量简化的渲染版作为备选
