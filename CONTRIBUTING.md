# Contributing

Thanks for considering improvements to `math-mode-switcher`.

## What kinds of contributions are useful

- Better prompt patterns for render / source / dual modes
- More robust cross-model wording conventions
- Better examples for academic writing, patent drafting, and technical reporting
- Documentation improvements in either Chinese or English
- Additional scenario-specific guidance, such as classroom use or review workflows

## Contribution principles

- Keep trigger phrases short and operational
- Prefer stable, cross-model-compatible wording over platform-specific tricks
- Avoid adding unnecessary verbosity to the skill itself
- When adding examples, show both the user instruction and the expected behavior
- Keep the repository useful for both casual users and heavy formula users

## Recommended workflow

1. Update the skill or documentation
2. Add or revise examples if behavior changes
3. Reflect user-facing changes in `CHANGELOG.md`
4. Keep Chinese and English docs reasonably aligned

## Notes

This repository is intentionally small. Improvements should preserve its low-friction nature: the point is to reduce communication cost, not to turn the skill into a large framework.
