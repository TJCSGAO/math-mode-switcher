# Example Prompts

## Chinese

### Render mode

- `模式：渲染。把这段 LaTeX 按最终效果显示出来。`
- `渲染模式。让我看看这个公式排版后长什么样。`

### Source mode

- `模式：源码（latex）。把这个公式整理成可直接用于 PDF 的 LaTeX 代码。`
- `模式：源码（md）。给我可复制的 Markdown 公式代码，不要渲染。`

### Dual mode

- `模式：双模式。先渲染，再给我可复制源码。`
- `双模式。我要一边看效果，一边复制到文档里。`

## English

### Render mode

- `Mode: render. Show me how this LaTeX looks when rendered.`
- `Render mode. Preview the final visual form of this equation.`

### Source mode

- `Mode: source (latex). Return LaTeX code I can paste into a PDF workflow.`
- `Mode: source (md). Return copyable Markdown math code only.`

### Dual mode

- `Mode: dual. Render it first, then provide reusable source code.`
- `Dual mode. I want to inspect the visual result and copy the code.`
